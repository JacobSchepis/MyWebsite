# MyWebsite (work in progress)

My personal portfolio site, built with ASP.NET Core Razor Pages. It has Home, About,
Projects and Contact pages, with a responsive layout using CSS grid and a mobile menu.

The structure and styling are in place; the project write-ups and images are still
placeholders.

## Built with

C#, ASP.NET Core 8 Razor Pages, HTML, CSS, Bootstrap.

## Running it

Needs the [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
dotnet run
```
